# OdysseyWM
A Sway-based Linux desktop environment inspired by Omarchy. Navigate Beyond.

## Fastfetch

Boxed layout with Nerd Font icons (mirrors the Omarchy style).

```bash
sudo cp configs/fastfetch/bin/* /usr/local/bin/
mkdir -p ~/.config/quattro/branding
cp configs/branding/about.txt ~/.config/quattro/branding/
sudo cp configs/fastfetch/config.jsonc /etc/fastfetch/config.jsonc
```
